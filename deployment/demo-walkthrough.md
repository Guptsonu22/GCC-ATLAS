# GCC Atlas — Reviewer demo walkthrough (5–10 minutes)

Use this script on the public URL (or any locally-running instance: `npm run dev:api` + `npm run dev:web` → http://localhost:5173).

1. **Dashboard (landing).** Read the scope note: "Counts reflect the GCC Atlas tracked dataset only, not the total number of GCCs in India." · 46 tracked GCCs across 12 cities; city-footprint and sector-mix charts; *Verification ledger* at the bottom shows how many records carry verified vs estimate-only evidence.
2. **City Intelligence → Compare Workspace.** Pick Bengaluru + Pune (click the pill). Every cell in the metric matrix carries an EST badge; hover any cell for its metric definition; provenance chip opens the source record. Bilateral text at the bottom: "Estimates come from public market commentary and must be re-verified…" and ""Not available" means no verified record on file — not zero."
3. **Save + share.** Name the comparison "Hub shortlist — Q4 review" → *Save to my session*. Reload the page — the comparison survives (session-scoped server-side persistence). *Copy link* gives the reviewer a shareable URL with the same city set; *CSV* downloads the matrix.
4. **GCC Explorer.** Search "Nova" (or any fragment); filter by sector/status; sort by employees; pagination. Open a company (e.g., ABB India) — the profile shows source rows with publisher, verification status, and *last verified date*.
5. **Sources.** Every source with publisher, type, confidence, verification state, and *where used*: expand any source row to see which records cite it (reverse usage). This page is the audit room for every number shown elsewhere.
6. **AI Assistant (demo mode).** Ask the flagship scripted question: *"Which city should a 150-person engineering GCC consider first: Hyderabad or Pune?"* — the answer arrives structured: direct answer, key findings, a comparison table with explicit estimates, evidence-backed facts (each with Source chips that deep-link to the record), recommendations clearly separated from facts via basis labels, and explicit *missing information*. Note the honesty banner: recommendations are rule-based heuristics here (no AI key configured on this deployment). Try "Which tracked GCCs have announced expansion activity recently?" for time-window behaviour.
7. **Providers.** Filter `capability = staffing` — only staffing-capable providers remain (TeamLease, xpheno). Provider profiles show verified attributes + case studies only where sourced; "not available" is never silently blank.
8. **Saved (optional).** The Saved page lists session-scoped saved comparisons with rename/delete — opening another browser profile shows an empty list (isolation by design).

**What proves the thesis in this walkthrough**: every figure traces to a source in two clicks; conflicts and gaps are labelled instead of smoothed ("not yet tracked", draft policies, dual Kerala targets, placeholder source rows); the assistant either cites or declines — it never invents.
